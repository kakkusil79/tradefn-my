# 한빛식당 점심 기록 정제 규칙

> (가상) 한빛정밀(주) 본사 구내식당 '한빛식당'의 가상 기록. 원본 `labs/day3/lab-c/hanbit_lunch_log.csv`는 읽기만 하고, 이 표 그대로 `scripts/lunch_clean.py`가 적용한다.
> 적용 순서: R1 → R2 → R3 → R4 → R5 → **R10** → R6 → R7 → R8 → R9 (R10은 나중에 더한 규칙이지만 R6가 출근예정을 쓰므로 R6보다 먼저).

| 번호 | 규칙 | 왜 |
|---|---|---|
| R1 | 날짜를 `YYYY-MM-DD`로 바꾼다 — `2026.3.2` · `2026/03/02` · `3월 2일`. 연도가 없으면 10–12월은 2025년, 1–9월은 2026년 | 날짜 형식이 섞여 있으면 정렬 · 중복 찾기 · 요일 계산을 할 수 없다 |
| R2 | 요일은 적힌 글자를 버리고 날짜에서 다시 계산한다(월 · 화 · 수 · 목 · 금) | `월요일` · `Mon`처럼 표기가 섞여 있고, 날짜와 맞지 않는 요일도 있을 수 있다 |
| R3 | 비고가 `휴무`인 줄은 뺀다 | 식당이 안 연 날(출근 0 · 식수 0)은 예보할 대상이 아니다 |
| R4 | 같은 날짜가 두 줄이면 비고에 `재집계`가 든 줄을, 없으면 나중 줄을 남긴다 | 하루가 두 번 세어지면 평균과 학습이 한쪽으로 쏠린다 |
| R5 | 식수가 빈칸인 줄은 뺀다(지어내지 않는다) | 식권 기계 고장으로 못 센 날 — 맞히려는 숫자를 지어낼 수 없다 |
| R10 | 출근예정 빈칸은 같은 요일의 바로 앞 기록 4개(출근예정이 있는 줄)의 가운데 값(median)을 반올림해 채운다 | 출근예정은 식수를 설명하는 재료이고 R6 판정에도 쓰인다. 같은 요일 최근 값이 가장 가까운 추정이다 |
| R6 | 식수가 출근예정보다 많거나 출근예정의 20% 미만이면 그 줄을 뺀다. 비고가 `수기 집계`인 줄 — **결정: 뺀다.** 이유: 프롬프트에 적힌 이유 없음 — 확인 필요 | 출근보다 많이 먹거나(예: 9999) 너무 적은 식수는 입력 실수로 보인다 |
| R7 | 날씨는 맑음 · 흐림 · 비 · 눈 넷으로 — `맑` · `sunny` → 맑음 / `구름많음` · `cloudy` → 흐림 / `rain` · `우천` · `소나기` · `흐리고 비` → 비 / `snow` → 눈 / 빈칸 → 모름 | 같은 날씨가 여러 이름이면 '비 오는 날' 같은 비교가 갈라진다 |
| R8 | 최고기온은 `℃` · `°C` · 공백을 떼고 숫자만 남긴다(빈칸은 빈칸으로 둔다) | 단위가 붙으면 숫자로 계산할 수 없다 |
| R9 | 이름 통일 — `돈까스` → 돈가스 · `카레라이스` → 카레 · `제육` → 제육볶음 · `치킨마요덮밥` → 치킨마요 · `김치 찌개` → 김치찌개 · `외부손님` → 외부 손님 방문 · `전사교육` → 전사 교육 | 같은 메뉴 · 행사가 여러 이름이면 메뉴별 · 행사별 비교가 갈라진다 |

마지막 정리: 월급날 `Y` → 1 · 빈칸 → 0, 출근예정 · 식수는 정수로 바꾸고 날짜순으로 `workbench/day3/outputs/lunch_clean.csv`에 저장한다(UTF-8 BOM, 열은 원본과 같은 10개). 규칙마다 고친(뺀) 줄 수는 `workbench/day3/outputs/lunch_clean_log.md`에 적는다.
